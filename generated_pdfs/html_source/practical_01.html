Project Overview & Technology Stack

FixIt — Smart Campus Maintenance Management System: An industrial facilities reporting and tracking single-page web application designed for university students, faculty, and administrative staff to submit infrastructure complaints, monitor dispatch progress, and view SLA standards across campus departments.

Technology Stack: HTML5 Semantic Elements, CSS3 Custom Properties, Bootstrap 5.3 Framework, Bootstrap Icons, Responsive Flexbox & Grid.

Theoretical Background & Concepts

1. Semantic HTML5 Architecture

HTML5 introduces semantic tags that convey structural meaning to search engines, screen readers, and browsers. Key tags used include <header>, <nav>, <section>, <article>, and <footer>, eliminating non-semantic <div> soup and enhancing accessibility (WCAG 2.1).

2. CSS3 Box Model & Custom Properties

The CSS3 Box Model governs layout dimensions via content, padding, border, and margin. FixIt employs universal box-sizing: border-box and root CSS variables (--primary-dark: #202522, --primary-accent: #E8752A, --surface-bg: #F7F5EF) for uniform editorial theming and responsive maintainability.

3. Bootstrap 5 Grid System & Breakpoint Mechanics

Bootstrap utilizes a mobile-first 12-column flexbox grid. Breakpoints (col-12 col-md-6 col-lg-4) dynamically collapse desktop layouts into single-column flows on mobile viewports (375px), guaranteeing zero horizontal overflow.
