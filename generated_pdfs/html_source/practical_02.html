Theoretical Background & Concepts

1. ES6 Array Manipulation Engine

JavaScript provides higher-order functional array methods that operate immutably or mutably:

  • filter(): Evaluates multi-criteria predicates (category, priority, search string).
  • find() / findIndex(): Locates specific tickets by ID for status updates.
  • splice(): Removes target records from array storage upon user confirmation.
  • reduce(): Dynamically computes live KPI counts (Pending, In Progress, Resolved).

2. JSON Serialization & Deserialization

JSON.stringify() converts JavaScript object trees into standardized JSON strings for storage or inspection, while JSON.parse() reconstructs active memory structures. This simulates client-server data exchange protocols.

3. Input Validation & Error Handling

Client input is validated prior to array insertion using regular expressions (Email: /^[^\s@]+@[^\s@]+\.[^\s@]+$/; Phone: /^[6-9]\d{9}$/). When validation fails, descriptive error messages are rendered dynamically to prevent state corruption.

/**
 * Explicitly demonstrates JSON.stringify() and JSON.parse()
 * Updates the JSON inspector box for viva demonstration.
 */
function updateJsonInspector() {
    // 1. Serialization: Convert JavaScript Array to JSON string
    const jsonData = JSON.stringify(issues, null, 2);

    // 2. Deserialization: Verify conversion back to JS Array
    const parsedData = JSON.parse(jsonData);

    // 3. Render into Inspector element
    if (jsonDisplay) {
        jsonDisplay.textContent = jsonData;
    }
    if (jsonByteSize) {
        const bytes = new Blob([jsonData]).size;
        jsonByteSize.textContent = `${bytes} bytes (${parsedData.length} records)`;
    }
}

function setFieldValidation(inputElement, isValid, errorMessage = "") {
    const errorDiv = document.getElementById(`error-${inputElement.id.replace("input-", "")}`);
    if (isValid) {
        inputElement.classList.remove("is-invalid");
        inputElement.classList.add("is-valid");
        if (errorDiv) errorDiv.style.display = "none";
    } else {
        inputElement.classList.remove("is-valid");
        inputElement.classList.add("is-invalid");
        if (errorDiv) {
            if (errorMessage) errorDiv.textContent = errorMessage;
            errorDiv.style.display = "block";
        }
    }
    return isValid;
}
